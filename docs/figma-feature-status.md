## 피그마에는 없지만 출시 전에 필요한 것

화면 설계에는 없지만 실제 서비스로 내려면 필요한 기능입니다. 위 요약 개수에는 넣지 않았습니다.

| 기능 | 상태 | 비고 |
|---|---|---|
| 이메일 인증(가입 시 본인 이메일 확인) | ⬜ | 지금은 형식만 검사, 남의 이메일로도 가입 가능 |
| 비밀번호 변경 | ⬜ | 비밀번호 찾기(A02)와 함께 |
| 로그아웃 · 토큰 강제 만료 | ⬜ | 리프레시 토큰을 서버에 저장하지 않아 강제로 막을 수 없음 |
| 위치 조작 방지 | ⬜ | 앱이 보낸 좌표를 그대로 신뢰, 이동 속도 검증 등 필요 |
| 접근 허용 주소 제한(CORS) | ⬜ | 지금은 모든 출처 허용, 프론트 도메인 확정 후 제한 |
