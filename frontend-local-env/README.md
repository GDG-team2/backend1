# 프론트엔드 로컬 테스트용 환경변수

프론트엔드 앱([GDG-team2/frontend](https://github.com/GDG-team2/frontend))을 실제 백엔드 서버에 연결해서 회원가입·로그인을 테스트할 때 쓰는 설정입니다.

## 왜 필요한가요?

프론트 회원가입 버튼은 약관 주소 3개(`EXPO_PUBLIC_*_TERMS_URL`)가 `https://`로 설정되어 있어야만 활성화됩니다.
설정이 없으면 모든 칸을 채우고 약관을 체크해도 버튼이 눌리지 않습니다. (`src/constants/legal.ts`, `src/app/index.tsx` 참고)

이 폴더의 `frontend.env`에는 테스트용 임시 약관 주소가 들어 있어서 로컬에서 바로 회원가입을 해볼 수 있습니다.

## 사용 방법

1. 이 폴더의 `frontend.env`를 **프론트엔드 프로젝트 루트**에 `.env`라는 이름으로 복사합니다.

   ```
   frontend/
   ├── .env          ← 여기에 복사 (package.json과 같은 위치)
   ├── package.json
   └── src/
   ```

2. 의존성을 설치하고 실행합니다. (프론트는 Bun을 사용합니다)

   ```bash
   bun install
   bun run web --port 8081 --clear
   ```

   - 웹: http://localhost:8081
   - 폰(Expo Go): `bun run start --go` 후 QR 코드 스캔 (PC와 같은 와이파이)

   > `.env`를 바꾼 뒤에는 반드시 서버를 껐다 켜야 하고, `--clear`로 캐시를 지워야 새 값이 반영됩니다.

3. 회원가입 화면에서 아래 조건으로 입력합니다.
   - 비밀번호: 영문 + 숫자 포함 8자 이상 (예: `test1234`)
   - 동네 코드: 숫자 10자리 (예: `1168010100` 강남구 역삼동)
   - 필수 약관 3개 체크

## 주의

- 프론트의 `.env`는 `.gitignore`에 포함되어 있어 프론트 저장소에는 올라가지 않습니다.
- `example.com` 약관 주소는 **로컬 테스트 전용**입니다. APK 등 배포용 빌드에는 실제 약관 원문 주소를 빌드 환경변수로 넣어야 합니다.
- 서버 없이 가짜 데이터로만 화면을 보고 싶다면 `EXPO_PUBLIC_USE_MSW=true`로 바꾸고, 로그인 화면의 `QA 모드로 바로 둘러보기`를 누르세요.
- Render 무료 서버는 쉬고 있다가 첫 요청 때 깨어나므로 첫 로그인·가입이 1분 가까이 걸릴 수 있습니다.
